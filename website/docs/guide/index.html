Alloy guide

Read in order, or jump to what you need. Every code block here is compiled as a doc-test by cargo test -p alloy-ui --doc, so the snippets stay true.

  1. Getting started: install the tool, your first app, testing without a screen
  2. State and bindings: handlers, at!, local, persistence
  3. Layout: col!, row!, gaps, fill, scroll
  4. Widgets: the catalogue
  5. Records and forms: derive(Record), crud, validation, wizards
  6. Async resources: loading, errors, retry, refresh, keyed data and cancellation
  7. Multi-window
  8. Shortcuts, palette, toasts, undo
  9. Theming
  10. Bundling
  11. Capabilities and IPC
  12. The dev loop: alloy dev, live views that reload on save, the F12 inspector
  13. Localization: t!, plurals, switching language, right-to-left
  14. Navigation: routes, back and forward, breadcrumbs
  15. Testing: Harness, fill, expect, snapshots
  16. Coming from iced or egui: side-by-side code and a porting checklist
  17. Shipping: signing, notarisation, MSIX and Flatpak, signed auto-update, crash reports
  18. Desktop integration: menu bar, tray, notifications, file dialogs, global hotkeys
  19. System integration: drag and drop, deep links, window effects, rich clipboard, OS settings
  20. Visual widgets: canvas, charts, calendar, kanban, node graph, 3D, media
  21. Mobile: Android and iOS builds, touch, safe areas (prototype)

Design background: ARCHITECTURE.md, DECISIONS.md, DESIGN.md. API reference: cargo doc --open -p alloy-ui.
