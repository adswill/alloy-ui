# Changelog

## 0.2.0
- Language server for `.alloy` files (`alloy lsp`): diagnostics, completion, hover.
- Commands: run `alloy dev`, run `alloy test`, restart the server; setting `alloy.server.path`.
- Requires VS Code 1.82 or newer.

## 0.1.0

* 21 Rust snippets (20 compiled against the crate by `test/check_snippets.py`), 8 `.alloy` snippets.
* TextMate grammar and language configuration for `.alloy` live views.
