# Alloy logo

The mark is a fused ingot: two metals (purple and blue) poured into one bar.

| File | Use |
|---|---|
| `alloy-mark.svg` | The mark alone, on any background |
| `alloy-lockup-light.svg`, `alloy-lockup-dark.svg` | Mark and wordmark for light and dark backgrounds (text is outlined) |
| `alloy-icon.svg`, `alloy-icon-light.svg` | App icon tiles |
| `alloy-favicon.svg`, `alloy-favicon.ico` | Simplified mark for 16 to 48 px (no glints, a straight seam) |
| `png/` | Raster exports. `crates/cli/assets/icon-{256,512}.png` are the default bundle icon |

Use the favicon artwork below 48 px; use the full mark above that.
